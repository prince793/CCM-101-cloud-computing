## Discussion Questions

**1. Which cloud provider offers the broadest range of services?**

AWS offers the broadest range of services, with over 200 distinct offerings spanning compute, storage, databases, analytics, AI/ML, IoT, and more. Its head start since 2006 has allowed it to build out the deepest and most mature service catalog of the three providers.

**2. Which provider best integrates with Microsoft technologies?**

Microsoft Azure best integrates with Microsoft technologies, since it is built by Microsoft itself. It offers native compatibility with Windows Server, Active Directory (via Microsoft Entra ID), and Microsoft 365, making it the natural choice for organizations already running Microsoft-based infrastructure.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

Google Cloud Platform is strongest in AI and Kubernetes. It created Kubernetes and offers Google Kubernetes Engine (GKE), widely regarded as the most mature managed Kubernetes service. GCP's Vertex AI and TensorFlow ecosystem also give it a strong edge in machine learning workloads.

**4. Which cloud platform would you personally choose and why?**

I would personally choose AWS for general-purpose projects because of its wide service selection, extensive documentation, and large community support, which make it easier to find solutions and best practices. However, for AI/ML-focused or Kubernetes-heavy projects, GCP would be the stronger choice, and for organizations already relying on Microsoft products, Azure would make the most sense.
