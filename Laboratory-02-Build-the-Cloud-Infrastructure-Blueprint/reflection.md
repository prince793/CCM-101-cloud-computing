# Mission Reflection

**1. Which cloud infrastructure component do you think is the most important? Why?**

For me, compute resources are the most important cloud infrastructure component. Without processing power, none of the other components—storage, networking, or identity management—can actually run applications or deliver services. Compute is what transforms stored data and network connections into real, usable outputs for end users.

**2. How does Linux support cloud computing?**

Linux plays a huge role in cloud computing because most cloud servers, containers, and virtual machines run on it due to its stability, open-source nature, and flexibility. It gives engineers direct access to system-level tools for monitoring resources, managing processes, and configuring networking, which are all essential when deploying and maintaining cloud infrastructure.

**3. Why is technical documentation important before deploying infrastructure?**

Technical documentation ensures that every design decision is recorded, understood, and can be reviewed before actual deployment. It helps prevent costly mistakes, allows teams to collaborate effectively, and serves as a reference for troubleshooting or scaling the infrastructure in the future.

**4. What new skills did you learn during this laboratory activity?**

I learned how to investigate a Linux server environment using terminal commands to identify hardware and software resources such as OS version, CPU, RAM, and disk capacity. I also gained a clearer understanding of how to compare cloud provider services and document technical findings professionally using Markdown.

**5. How has your GitHub portfolio improved after completing this mission?**

My GitHub portfolio is now more organized and professional, with a dedicated folder structure containing detailed technical reports, comparisons, and diagrams. This mission helped me practice maintaining a structured repository through meaningful commits, which reflects real-world cloud engineering documentation practices.
